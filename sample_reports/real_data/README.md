
# Sample Reports — Real AROL Data

Generated against the full 90-day telemetry dataset (55,128,924 closures,
36 heads) on the Parquet-optimized closures pipeline.

Every report below follows the structure defined in
[`../report_template.md`](../report_template.md).

| File                                        | Command                                                                                   | Why it matters                                                                                                                                                                                                                                                                                                                       |
| ------------------------------------------- | ----------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `01_multi_tool_root_cause_h29_h30.md`     | `ask "which head has the most problems and why?"`                                       | Deepest tool chain (6 tools). Cross-validates an earlier manual finding (Feb 25 H29 spike) through independent automated reasoning; surfaces a new discovery (H30 zero-torque sensor anomalies); demonstrates hypothesis elimination (torque, drift, idle time all ruled out before isolating the real cause).                       |
| `02_idle_time_per_head.md`                | `ask "what is the idle time for each head?"`                                            | Confirms idle detection at full scale after a performance fix (per-head lazy loading: ~2s/head vs. prior out-of-memory crashes). Near-uniform idle time across heads sets up the machine_idle_periods finding.                                                                                                                       |
| `03_machine_idle_periods.md`              | `ask "were there times the entire machine was idle at once?"`                           | Directly confirms and dates real machine-wide shutdown events — including a 59-hour and a 51-hour full-line stop — proving the synchronized-stoppage hypothesis first suspected in an earlier head_health investigation. Fixed a separate memory-scaling issue (weekly time-window chunking) to compute this at full 90-day scale. |
| `04_plot_failures_per_head.md` + `.png` | `ask "plot failure count per head"`                                                     | Visual evidence — a bar chart making the H29 outlier immediately obvious (117 failures vs. next-highest at 78), where the equivalent success-rate-percentage chart is uninformative since every head rounds to ~100%. Confirms the full plotting suite works correctly on the optimized pipeline (15.5s total).                     |
| `05_h30_zero_torque_investigation.md`     | `ask "the zero-torque closures for head 30 - are they real failures or sensor errors?"` | Conclusively resolves a data-quality question first raised in report 01. Cross-references timestamps across heads to find the same anomaly on H07, correctly diagnosing a shared telemetry glitch rather than a head-specific fault. Strongest single demonstration of multi-step inferential reasoning in the project.              |
