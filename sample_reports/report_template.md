\# Report Template



Every report generated by the AROL telemetry agent follows this

structure, enforced via the system prompt in `src/agent/orchestrator.py`:



\## Goal

What question is being answered.



\## Data used

Which dataset/subset the analysis draws from.



\## Analyses executed

Which tool(s) were called, and in what order.



\## Findings

The actual results - numbers, patterns, comparisons.



\## Confidence/limits

Honest caveats: sample size, what the data can't confirm, tool limitations.



\## Suggested next checks

Concrete follow-up questions or tools that would extend the investigation.



\---



This structure is deliberately consistent across every canned report

(`report kpi/anomalies/drift`) and every free-text question (`ask`),

so outputs are comparable and predictable regardless of how the

question was phrased.
